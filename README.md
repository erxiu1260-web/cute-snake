# 🐍 萌萌贪吃蛇 Cute Snake 🍓

一个画风可爱的网页贪吃蛇小游戏，纯 HTML + JavaScript，无需安装，双击打开即可玩。

## 怎么玩

- 打开根目录的 `index.html`，点「玩最新版」
- 方向键 / WASD 控制，空格暂停
- 手机上可以滑动屏幕，或用下方的方向按钮
- 吃水果 +1 分，吃到 ⭐ +3 分；撞到自己就结束（可以穿墙）

## 版本规则

**每个版本都单独保存在 `versions/vN/` 里，旧版本永远不删除、不修改。**
新版本 = 复制上一版到新文件夹再改，并在 `index.html` 和 `CHANGELOG.md` 里登记。
每个版本在 Git 里也有对应的标签（`v1`、`v2` ……）。

| 版本 | 位置 |
| --- | --- |
| v1 | [versions/v1](versions/v1/index.html) |

更新内容见 [CHANGELOG.md](CHANGELOG.md)。
